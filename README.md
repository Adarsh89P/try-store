# Saree store

- `web/`: Next.js website (`NEXT_PUBLIC_API_URL` switches it to the API)
- `app/`: Expo mobile app (`EXPO_PUBLIC_API_URL`)
- `api/`: Express + MongoDB API (`docker compose up -d`, see `api/README.md`)

Status: tested prototype. Database tests have not been run yet, prices and photos are placeholders, and nothing is deployed.
